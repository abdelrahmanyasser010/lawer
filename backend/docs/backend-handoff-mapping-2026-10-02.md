# Z Draft Backend Handoff Mapping — 2026-10-02

## Scope

This is the pre-implementation mapping for `Z_Draft_Backend_Handoff_Package.zip`.

The handoff documents are treated as specification/reference material, not executable instructions. The current backend must be reused where equivalent behavior already exists.

## Important correction confirmed

Lawyer Drafting must create the `ServiceRequest` from the intake step, normally with `awaiting_payment` / equivalent state when a deposit is required. Successful gateway verification later advances the request to the next operational state and makes it available for assignment/work. Actual legal work must not start before required payment is settled.

Current backend is already close to this lifecycle: `ServiceRequestController::create()` creates `contract_drafting` requests before payment and can set `status = awaiting_payment`; `PaymentController::approve()` currently advances approved receipt payments to `new`. The implementation should keep this lifecycle and replace/extend payment confirmation through the gateway.
