# خريطة تنفيذ القوالب القانونية - Z draft

التاريخ: 2026-07-31

## القرار النهائي

تم تحويل البيع والإيجار إلى Parent Templates، ويختار المستخدم الصيغة القانونية قبل بدء المعالج. السعر يظل مرتبطًا بالقالب الرئيسي، وليس بالصيغ الفرعية، في الـMVP الحالي.

```text
apartment_sale
├── preliminary_sale
├── registrable_sale
└── inherited_sale

rental
├── residential_lease
├── commercial_lease
└── administrative_lease
```

الإضافات الطويلة لا تندمج داخل صفحات العقد الأساسي، بل تصدر كمستندات مستقلة مرتبطة به:

```text
sale_installment_schedule
└── ملحق جدول سداد الأقساط

rental_handover_inventory_report
└── محضر استلام وجرد العين المؤجرة
```

## مصادر البيع

### 1. البيع الابتدائي

- المفتاح: `preliminary_sale`
- المستند: `عقد بيع ابتدائي Z DRAFT.pdf`
- أهم الاختلافات المنفذة:
  - تسلسل العقود والتصرفات السابقة.
  - الحصة الشائعة والأجزاء المشتركة.
  - وضع الجراج أو مكان السيارة.
  - موقف التصالح ومسؤولية استكماله.

### 2. البيع القابل للتسجيل

- المفتاح: `registrable_sale`
- المستند: `عقد بيع قابل للتسجيل في الشهر العقاري Z DRAFT.pdf`
- أهم الاختلافات المنفذة:
  - نوع السند القابل للشهر.
  - رقم السند والسنة ومأمورية الشهر العقاري.
  - طريقة استكمال نقل الملكية.
  - الطرف المتحمل لرسوم التسجيل.
  - ملاحظات ومستندات ملف التسجيل.

### 3. البيع عن طريق الميراث

- المفتاح: `inherited_sale`
- المستند: `عقد بيع وحدة عن طريق الورث (Z DRAFT).pdf`
- أهم الاختلافات المنفذة:
  - اسم المورث وإعلام الوراثة والمحكمة والتاريخ.
  - حصة البائع الموروثة.
  - سند انفراد البائع بالتصرف أو موافقات باقي الورثة.
  - قائمة باقي الورثة وأصحاب الحقوق.
  - القاصر أو ناقص الأهلية وإذن محكمة الأسرة عند الحاجة.

## ملحق البيع الاختياري

- المفتاح: `sale_installment_schedule`
- المستند: `ملحق ( جدول الاقساط ) Z DRAFT.pdf`
- وضع الإخراج: `separate_annex`
- يطبق على أنواع البيع الثلاثة.
- يحتوي على:
  - تاريخ الملحق وتاريخ/مرجع عقد البيع وعدد النسخ.
  - إجمالي الثمن والمقدم والمتبقي.
  - عدد الأقساط وقيمة القسط والدورية.
  - أول وآخر استحقاق.
  - جدول متكرر لكل قسط وطريقة السداد والإيصال.
  - السداد المبكر وأثر التأخير.
- قواعد التحقق:
  - طريقة السداد بالأقساط تستلزم اختيار الملحق.
  - إجمالي الثمن = المقدم + المتبقي.
  - عدد صفوف الجدول = عدد الأقساط.
  - مجموع الأقساط = المبلغ المتبقي.

## مصادر الإيجار

### 1. الإيجار السكني

- المفتاح: `residential_lease`
- المستند: `عقد ايجار سكني (Z DRAFT).pdf`
- أهم الاختلافات المنفذة:
  - نوع العين السكنية.
  - مفروشة أو غير مفروشة.
  - الجراج والمخزن والحديقة والروف.
  - الغرض السكني مثبت من الصيغة ولا يكتبه المستخدم كنص قانوني.

### 2. الإيجار التجاري

- المفتاح: `commercial_lease`
- المستند: `عقد ايجار تجاري ( Z DRAFT ).pdf`
- أهم الاختلافات المنفذة:
  - موقع الوحدة داخل مول أو سوق أو مشروع أو شارع.
  - الترخيص والميزانين والواجهات.
  - المخزن ومنطقة التحميل والتنزيل.
  - النشاط التجاري ومسؤولية التراخيص واللافتة.

### 3. الإيجار الإداري

- المفتاح: `administrative_lease`
- المستند: `إداري عقد ايجار Z DRAFT().pdf`
- أهم الاختلافات المنفذة:
  - موقع المقر داخل برج أو مشروع أو مبنى متعدد الاستخدامات.
  - نوع الاستعمال الإداري أو المهني.
  - وصف النشاط واستقبال الزوار واللافتة ومواعيد العمل.

## ملحق الإيجار الاختياري

- المفتاح: `rental_handover_inventory_report`
- المستند: `محضر استلام وجرد العين المؤجرة Z DRAFT.pdf`
- وضع الإخراج: `separate_annex`
- يطبق على أنواع الإيجار الثلاثة.
- يحتوي على:
  - تاريخ ووقت الاستلام.
  - قائمة حالة العين المسبقة: دهانات، أسقف، أرضيات، أبواب، أقفال، شبابيك، زجاج، كهرباء، إضاءة، سباكة، مطبخ، حمامات، تكييفات وسخان.
  - وسائل الدخول والمفاتيح والريموتات والكروت.
  - جرد متكرر للمنقولات والتجهيزات.
  - أرقام وقراءات العدادات.
  - اختيار توثيق الحالة بالصور أو الفيديو ورفع مراجع الملفات.
  - عدد النسخ والملاحظات والتحفظات وإقرار الطرفين.

## قواعد UX المنفذة

- لا يكتب المستخدم مادة قانونية حرة.
- المستخدم يجيب على أسئلة وحقائق سهلة.
- الصيغة القانونية تحدد `rental_purpose` أو طبيعة البيع تلقائيًا.
- الخطوات تعتمد على مفاتيح ثابتة وليس على أرقام الخطوات، حتى لا يكسر إدخال Variant أو ملحق ترتيب المعالج.
- يمكن تغيير نوع العقد من رأس المعالج، مع تنبيه أن ذلك يبدأ مسودة جديدة.
- الشركات والمنشآت مدعومة كطرف، مع التحقق من بيانات السجل والبطاقة الضريبية والممثل القانوني.
- الحقول المشتركة للوحدات تشمل الكمبوند/المشروع والقطعة والمجاورة واسم المبنى والمطبخ والعدادات وحالة الإشغال حيث تنطبق.
- الإيجار يدعم مهلة الإخطار قبل عدم التجديد ومدة رد التأمين بعد التسليم والمخالصة.

## حدود النسخة الحالية

- النصوص القانونية النهائية الطويلة لم توضع ككتلة Hardcode داخل React.
- التعريف الحالي يحدد الصيغة والحقول ومفاتيح المواد ومصدرها القانوني.
- عند تنفيذ الباك الحقيقي، تحفظ نصوص المواد وإصداراتها داخل `legal_clause_library` وتستخدم في توليد PDF والعقد النهائي.
- الباك إند التشغيلي الحالي Laravel + PostgreSQL، وتعريفات القوالب القانونية مزروعة من ملفات JSON داخل `backend/database/template-definitions`.
