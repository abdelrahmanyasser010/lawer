# تصنيفات القوالب ونسخ عائلة جديدة

- يوجد الآن كيان مستقل لتصنيفات العقود، ويمكن للتصنيف أن يضم عائلات قوالب متعددة.
- القوالب الحالية تُسند تلقائيًا إلى تصنيف `general` عند تشغيل الـ migration.
- من لوحة القوالب يمكن إنشاء تصنيف جديد، ثم اختيار التصنيف عند إنشاء أي عائلة عقد.
- إنشاء قالب جديد يمكن أن يبدأ من الصفر أو ينسخ أحدث إصدار متاح من قالب موجود (`sourceTemplateId`) إلى Version 1 مستقلة قابلة للتعديل.
- تغيير نص بند أو Schema أو ترتيب العناصر في القالب الجديد لا يغيّر القالب المصدر أو العقود التاريخية.
- كتالوج العميل يجمع القوالب ديناميكيًا تحت التصنيفات القادمة من لوحة الإدارة، لذلك إضافة تصنيف أو عائلة جديدة لا تحتاج تعديلًا برمجيًا في الواجهة.
