# تنفيذ عقود الخدمات والعمل الحر — V13

تم تنفيذ عائلة `freelancer` على آخر نسخة مصدر مرفوعة، مع الحفاظ على تعديلات المشروع الموجودة وعدم الرجوع إلى نسخة أقدم.

## القوالب الرئيسية

1. `visual_identity_design` — عقد تصميم الهوية البصرية.
2. `website_development` — عقد تطوير موقع إلكتروني.
3. `social_media_management` — عقد تقديم خدمات إدارة حسابات ومنصات التواصل الاجتماعي.

## الملاحق المستقلة

### تصميم الهوية البصرية
- `visual_identity_scope_annex` — نطاق العمل والمخرجات الفنية.
- `visual_identity_financial_annex` — المقابل المالي وآلية السداد وخطة التنفيذ.
- `visual_identity_approvals_annex` — الاعتمادات وإدارة التنفيذ.

### تطوير الموقع الإلكتروني
- `website_scope_annex` — نطاق العمل SOW.
- `website_technical_annex` — المواصفات الفنية TS.
- `website_project_data_annex` — بيانات المشروع.
- `website_delivery_annex` — محضر التسليم والاعتماد النهائي DAR.
- `website_sla_annex` — الصيانة والدعم الفني ومستويات الخدمة SLA.
- `website_future_development_annex` — التطويرات المستقبلية والأعمال الإضافية.

### إدارة منصات التواصل الاجتماعي
- `social_media_scope_annex` — نطاق الخدمات وبيانات المشروع SOS.
- `social_media_financial_annex` — المقابل المالي وآلية السداد.

## الترميز القانوني

- تم حفظ ملفات المصادر الأربعة عشر داخل `docs/legal-sources/freelance/`.
- تمت إضافة أداة قابلة لإعادة التشغيل: `tools/extract_freelance_sources.py`.
- تم استخراج وترميز **172 قسمًا قانونيًا** مع اسم ملف المصدر وأرقام الصفحات.
- النصوص لم تُستبدل بصياغات عامة ولم تُخترع بنود جديدة.
- الحقول الديناميكية تظهر في جداول بيانات العقد والملاحق، بينما تشير النصوص المصدرية إلى البيانات المثبتة بهذه الجداول عند مواضع الفراغات الأصلية.

## واجهة العميل

تمت إضافة مسار ديناميكي كامل لقالب `freelancer` داخل المعالج، ويشمل:

- اختيار نوع العقد.
- اختيار الملاحق المستقلة الملائمة لكل نوع.
- خطوات ديناميكية مختلفة لكل عقد ولكل ملحق.
- حقول فرد أو شركة وشروط ظهور بيانات الشركة.
- قوائم، اختيارات، مربعات تحديد، حقول مالية، تواريخ، نصوص طويلة، مرفقات، وجداول متكررة.
- رفع المرفقات من الحقول الديناميكية إلى API التخزين الخاص.
- مؤشر اكتمال للبيانات المطلوبة.
- نقل المستخدم مباشرة إلى الخطوة التي تحتوي على بيانات ناقصة.
- مراجعة نهائية للعقد والملاحق قبل الدفع.
- حفظ المسودة وإنشاء مرجع Backend قبل فتح الدفع.
- حماية البيانات الأساسية للطرفين بعد اعتماد الدفع.

## لوحة المكتب

- تعرض عائلة «عقود الخدمات والعمل الحر» بثلاثة أنواع.
- تستخدم نفس `Template Engine` ونفس تعريفات الحقول والملاحق.
- يستطيع المكتب إنشاء العقد لعميل موجود أو جديد أو للاستخدام الداخلي.
- يدعم محرر الحقول الديناميكية والـRepeaters والمرفقات.
- تم تحسين عرض اختيارات `radio` في واجهتي العميل والمكتب لتكون اختيارات واضحة بدل قائمة منسدلة.

## الباك إند

- تعريف القالب يدخل في Seed بالإصدار 2.
- تم تحديث مرجع القالب والـSeed القديم باسم العائلة الصحيح.
- التحقق من الحقول المطلوبة يتم من تعريف القالب نفسه.
- تمت إضافة قواعد مالية إضافية:
  - مجموع دفعات ملحق الهوية يجب أن يساوي إجمالي المقابل.
  - مجموع نسب دفعات الهوية يساوي 100% عند استخدام النسب.
  - مجموع دفعات ملحق إدارة التواصل يساوي قيمة المقابل.
  - ميزانية الإعلان مطلوبة عند اختيار حملات ممولة.
  - ملحق SLA يتطلب مستوى خدمة واحدًا على الأقل.
- قفل بيانات الأطراف يعمل تلقائيًا لأن خطوات العميل ومقدم الخدمة معرفة كخطوات هوية أساسية.
