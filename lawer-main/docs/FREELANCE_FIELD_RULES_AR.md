# قواعد حقول عقود الخدمات والعمل الحر

## قاعدة ملفات المصدر

- **البرتقالي:** حقل إجباري.
- **الأزرق:** حقل اختياري.
- **غير الملوّن:** إجباري افتراضيًا.
- النص الذي يذكر صراحةً «اختياري» أو «إن وجد» يُعامل كاختياري حتى لو لم يعتمد على اللون وحده.
- الخدمات والمخرجات التي أمامها مربعات اختيار لا تدخل في نطاق العقد إلا عند اختيارها.
- بيانات الشركة لا تظهر إلا عندما تكون صفة الطرف «شركة / منشأة»؛ وعند ظهورها تطبق عليها قاعدة اللون والإلزام.

## أمثلة مطبقة

### بيانات الأطراف
إجباري:
- الاسم.
- الجنسية.
- الرقم القومي أو رقم جواز السفر.
- العنوان.
- الهاتف.

اختياري:
- جهة الإصدار.
- تاريخ الإصدار.
- البريد الإلكتروني الشخصي.

مشروط بصفة الشركة:
- اسم الشركة.
- الشكل القانوني.
- السجل التجاري.
- الرقم الضريبي.
- الممثل القانوني وصفته وسند تمثيله.
- مقر الشركة.
- بريد الشركة وفق تمييز المصدر.

## مبدأ العرض في PDF

الألوان لا تظهر في المستند النهائي. تتحول إلى خصائص بيانات داخل المحرك:

```text
required = true / false
visibleWhen = شرط الظهور
options = الاختيارات المعتمدة
outputMode = separate_annex للملاحق المستقلة
```

العقد النهائي يعرض البيانات المكتملة بالأسود داخل جداول قانونية موحدة.
